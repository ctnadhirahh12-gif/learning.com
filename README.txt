LEARNING.CO — UPDATED COMPLETE WEBSITE

FILES
- index.html: Home, About SDG 4, Learn, Quiz, Game, quiz result, Help, FAQ and Contact form.
- style.css: responsive Gen-Z inspired purple, cyan, pink and yellow design.
- script.js: navigation, quiz/game logic, right/wrong audio, result fireworks and contact-form demo response.
- robot-mascot.gif: animated Learning.co robot mascot.

RUN
1. Extract this ZIP.
2. Open the Learning_co folder in Visual Studio Code.
3. Keep all files in the same folder.
4. Right-click index.html and choose Open with Live Server.
   Or double-click index.html to open it in a browser.

NEW FEATURES
- Quiz: a cheerful high-pitched sound plays for a correct answer; a lower two-tone sound plays for an incorrect answer.
- Game: the same correct/incorrect sound feedback plays after each player's answer.
- Animated robot mascot: included on Home and Learn pages.
- Footer: Help Centre links, expandable FAQs, Explore navigation and a Contact Information form.

IMPORTANT
- Contact form is currently a front-end demonstration. It validates the fields and displays a confirmation message, but does not send/store messages. To receive real submissions, connect a form service or backend.
- Quiz and game scores are temporary and are not saved after refresh.
- The game supports 2–5 students taking turns on one device.
- Videos require internet access and may be subject to YouTube embedding restrictions.
- Browser audio is triggered by the learner's answer click. Make sure device volume is on.
